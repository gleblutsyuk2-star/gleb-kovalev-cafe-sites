# Глеб Ковалёв — сайты для кафе

Оливковая палитра, русскоязычный одностраничный сайт, два действия на первом экране: «Кейсы» и «Обсудить проект». Telegram расположен справа в шапке.

Запуск: `npm run dev`. Сайт не требует установки зависимостей или сборки; исходные публичные файлы находятся в `dist/`.

## Содержание

Портфолио «Переговорка», «Четверг» и «Вкусное место» отмечено как концепты. Превью — снимки опубликованных сайтов, фотография взята из уже созданного проекта «Переговорка». На компьютере три кейса видны в одной сетке; на телефоне идут друг под другом. Процесс работы оформлен вертикальной шкалой. Декоративные подписи и нумерация разделов убраны.

Отзывы и показатели продаж не выдуманы. Стоимость определяется по задаче: суммы Adjoy обсуждались как ориентир, а собственные цены не были утверждены.

## Форма

Форма отправляет заявки на `glebkovalev077@gmail.com` через FormSubmit, выбранный пользователем. До получения писем владелец должен активировать адрес по письму FormSubmit. Telegram доступен независимо от почтового сервиса. Ошибки, тайм-аут и отсутствие подтверждённого ответа сохраняют содержимое формы. Данные не сохраняются в браузере.

На сайте нет аналитики. Информация о передаче данных FormSubmit открывается из формы и подвала. Перед открытием общего доступа необходимо подтвердить почту и проверить доставку реального тестового обращения.
