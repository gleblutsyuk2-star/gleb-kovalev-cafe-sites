# Глеб Ковалёв — сайты для кафе

Персональный сайт дизайнера и разработчика, который создаёт сайты для кафе и кофеен под ключ.

## Возможности

- портфолио с горизонтальной галереей проектов;
- три формата сайта: лендинг, многостраничный сайт и интернет-магазин;
- описание процесса работы и условий поддержки;
- адаптивная версия для компьютеров, планшетов и телефонов;
- форма заявки и прямые ссылки на Telegram и электронную почту;
- доступная навигация с клавиатуры и поддержка режима уменьшенной анимации.

## Технологии

Сайт написан на HTML, CSS и JavaScript без фреймворков и этапа сборки. Готовые публичные файлы находятся в каталоге `dist/`.

## Локальный запуск

```bash
npm run dev
```

После запуска адрес сайта появится в терминале.

## Публикация

Основная ветка `main` подключена к Vercel. Каждый новый коммит автоматически создаёт обновлённую публикацию сайта.

[Открыть сайт](https://gleb-kovalev-cafe-sites.vercel.app/)
