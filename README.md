# Глеб Ковалёв — сайты для бизнеса

Персональное портфолио дизайнера и разработчика: лендинги, сайты компаний и интернет-магазины.

## Локальный запуск

```sh
npm ci
npm run build
npm run dev
```

Адрес локального предпросмотра появится в терминале. Ничего не публикуется автоматически от этих команд.

## Где редактировать

- `src/home.html` — структура и тексты главной.
- `src/content.mjs` — услуги и семь вопросов-ответов.
- `src/projects.mjs` — общий набор трёх учебных проектов, ссылки и изображения.
- `src/templates.mjs` — общая навигация, подвал, информация о данных, схемы форматов и статические карточки.
- `dist/assets/logo-gk-header.svg` — выбранная угловатая монограмма с тёмно-синей лицевой стороной и синими гранями. Сборка создаёт её отдельную копию `logo-gk.svg` для статического главного экрана. Объёмная версия построена по этому же силуэту в `src/logo-geometry.mjs`.
- `src/logo-geometry.mjs`, `src/logo.mjs` — собственная объёмная GK-геометрия и управление.
- `src/gallery.mjs` — общий контроллер галереи на главной и `/projects/`.
- `src/viewport.mjs`, `src/motion.mjs` — отложенная загрузка, жизненный цикл и остановка невидимых сцен.
- `dist/styles.css`, `dist/script.js` — оформление, меню и форма.
- Существующие кафе-страницы в `dist/` остаются редактируемыми нишевыми материалами. Сборка обновляет их общую шапку, подвал и шрифты, но сохраняет основное содержание.

Готовые публичные файлы находятся в `dist/`. Главная, полная галерея, общие страницы услуг и 3D-бандлы создаются при сборке — редактируйте их исходники, а не сгенерированный HTML.

## Поведение

Объёмный гранёный GK реагирует на движение курсора без зажатой кнопки мыши. Горизонтальное движение накапливает поворот без ограничений; выход курсора не сбрасывает его. Один проход на ширину сцены даёт 162° вместо прежних 360°, с плавным доведением поворота за 1,1 секунды. Вертикальный наклон остаётся ограниченным. При фокусе на сцене клавиши ← / → вращают знак, нажатие меняет материал. Кнопки «Разобрать» и «Материал» работают с телефона и клавиатуры. Сохраняются шесть объёмных частей, изменение формы при разборке и три материала: тёмно-синий, синий и серебристый.

Широкие превью галереи проходят через общую неподвижную зону изгиба; деформация зависит от места в сцене, а не от центра отдельного проекта. Галерея поддерживает перетаскивание, горизонтальный жест и клавиши ← / → / Home / End. Полная галерея — страница основного сайта `/projects/`, с общей навигацией, подвалом и переходом к форме. Колесо мыши листает проекты только внутри галереи на этой странице; на главной вертикальная прокрутка остаётся обычной. Вертикальный жест пальцем прокручивает обе страницы.

Оформление вдохновлено Stripe: белая основа, тёмно-синий текст, сиреневые действия и локальная голубая/сиреневая/розовая/персиковая диагональ. GK остаётся без собственной подложки. Палитра и основные стили находятся в `dist/styles.css`.

Без JavaScript, WebGL или при уменьшенной анимации остаются статический знак и обычные карточки со ссылками. Изображения и ссылки относятся к учебным концептам, не к клиентским результатам. По просьбе владельца видимые отметки «Учебный концепт», нумерация и декоративные надзаголовки убраны; клиентские результаты или вымышленные отзывы не добавлялись.

## Проверки

```sh
npm run check
npm run test:browser
```

Браузерные проверки используют установленный Microsoft Edge в скрытом режиме. Форма проверяется через перехват ответов FormSubmit — тестовые письма не отправляются. Скриншоты находятся в игнорируемой папке `artifacts/redesign/`.

## Публикация

GitHub: [gleblutsyuk2-star/gleb-kovalev-cafe-sites](https://github.com/gleblutsyuk2-star/gleb-kovalev-cafe-sites).

Vercel использует исходники из корня репозитория: `npm ci`, затем `npm run build`; публичная папка — `dist`. Настройки сборки находятся в `vercel.json`. Перед публикацией выполняются обе команды из раздела «Проверки». Локальные `cafe-ten/`, `tmp/`, `node_modules/` и `artifacts/` не входят в публикацию.

Домен и canonical сохранены: [gleb-kovalev-cafe-sites.vercel.app](https://gleb-kovalev-cafe-sites.vercel.app/). Изменение домена не требуется для этого выпуска.
